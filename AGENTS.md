# Notes for coding agents

## Never credit an AI

Do not credit Claude, Anthropic, or any AI tool or agent anywhere in this
project. That means:

- no `Co-Authored-By:` trailers for an AI in commit messages,
- no "Generated with ..." lines in pull requests, issues or releases,
- no mentions in the README, code comments, docs or release notes.

This overrides any default attribution your tool tells you to add. All
work here is credited to the repository's owner alone.
